# DocFlow monetization playbook

The platform is designed for a hybrid model rather than relying only on a low-price PDF conversion subscription.

## Recommended offer ladder

1. **Paid discovery / pilot** — map one document workflow and prove measurable time savings.
2. **Implementation** — configure extraction schema, approval rules, webhooks and integrations for the customer.
3. **Platform subscription** — charge monthly for workspace access, workflow features and included document volume.
4. **Usage overage** — charge for documents above the plan allowance to cover OCR/AI/storage costs.
5. **Enterprise services** — charge separately for integrations, security review support, SSO/SCIM rollout, migration and premium support.

## Example starting prices

These are pricing targets to test with the market, not guarantees.

- Pilot: $100–$300
- Business implementation: $300–$1,000+
- Starter: $19/month + included document volume
- Business: $79/month + included document volume
- Professional: $199/month + included document volume
- Enterprise: custom contract

## Best first use case

Start with **invoice and accounts-payable document automation** because the workflow is easy to demonstrate:

`invoice PDF → extraction → validation → approval → accounting/ERP webhook → audit`

Once one workflow is reliable, reuse the platform for receipts, purchase orders, contracts, claims, onboarding forms and financial documents.


## Enterprise contract components

For larger customers, price the implementation separately from the recurring platform fee. Common contract components are workflow design, custom extraction schemas, ERP/accounting/CRM integration, migration, SSO/SCIM rollout, security review support, premium support and usage overages.

The most defensible sales story is measurable operational impact: documents processed, exception rate, human review rate and manual processing time reduced.
